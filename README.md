# Toronto Auto Theft Analysis

### Exploratory Data Analysis | Python | Data Visualization

An exploratory data analysis (EDA) project examining auto theft incidents in Toronto using publicly available Toronto Police Service crime data.

The project aims to identify patterns, explore distributions, and communicate insights through statistical analysis and data visualizations.

## Project Overview

Auto theft is a public safety concern in Toronto. Understanding how reported incidents vary over time and across geographic areas can help reveal meaningful patterns in crime data.

This project uses Python to explore Toronto auto theft statistics and present the findings through visualizations and descriptive analysis.

### Objectives

- Explore the structure and characteristics of the dataset.
- Identify patterns in reported auto theft incidents.
- Analyze relevant numerical and categorical variables.
- Create visualizations to communicate trends and distributions.
- Interpret the results and document key observations.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/berlinernesse/toronto-auto-theft-analysis.git
cd toronto-auto-theft-analysis
```

Install the Python dependencies:

```bash
pip install pandas numpy matplotlib seaborn
```

Run the analysis:

```bash
python Auto_Theft_Exploration.py
```

The script may require local dataset paths to be configured, depending on how the data files are loaded.

## Limitations

- The analysis describes patterns in reported incidents and does not establish causation.
- Results depend on the completeness and accuracy of the source data.
- Findings should be interpreted in the context of the dataset's reporting period and geographic coverage.
